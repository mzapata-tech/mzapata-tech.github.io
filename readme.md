# Mediveins AI

An intelligent medical automation system powered by:

- WhatsApp
- Twilio API
- Claude AI
- Google Apps Script
- Google Sheets

## Features

- Automated appointment scheduling
- Appointment confirmations
- AI-powered WhatsApp support
- Medical appointment management
- Workflow automation for clinics and secretaries

## Goal

Reduce manual administrative work and automate patient communication
through artificial intelligence.

## Project Status

Currently in testing and continuous improvement phase.
